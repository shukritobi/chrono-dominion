# Chrono Dominion art pipeline

## Single visual standard
- Camera: fixed orthographic isometric-style perspective, tested against the browser canvas.
- Terrain: diamond cell 64×32 logical pixels as the starting standard; revisit after calibration.
- Lighting: coherent primary light from upper-left; shadows always aligned.
- Authoring: Blender preferred for repeatable batch export; SketchUp or other modelling tools can provide source geometry.
- Characters: 8 directional animations (idle, move, fire, death, special if relevant).
- Vehicles: 32 directional rotations, turret-independent rotation when relevant.
- Buildings: standing, constructing, active, damaged, destroyed states.
- Scale: player must identify different classes at 100% and 75% in the actual game viewport.
- Export: transparent PNG/WebP frames, optional shadow/team-colour masks, metadata JSON, packed atlases. Preserve original editable sources.

## Names and folders

```text
art/
  concepts/
  sources/
    coalition/
    federation/
    psionic/
  renders/
  previews/
public/assets/
  atlases/
  metadata/
  audio/
```

For each asset family choose a unique ID in the 308-family register, e.g. `COA-VEH-001`. Each state/rotation should use a deterministic filename such as `COA-VEH-001_move_00.png`. Do not manually redraw directional variants.

## Quality control
All atlas frames must be consistent in registration, orientation, scale and shadow direction. Ensure no borrowed commercial game sprites, sounds or music appear in distributable builds. Maintain export logs and check in previews only when approved.
