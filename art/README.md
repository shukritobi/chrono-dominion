# Original art source

Place editable source models, concepts, batch-export scripts and render previews here. **Production sprite assets do not exist yet.** The currently playable demo draws original temporary shapes in Canvas 2D.

Use the naming and export requirements in [the art pipeline](../docs/ART-PIPELINE.md) and [production plan](../docs/asset-production/ASSET-PRODUCTION-PLAN.md). Each new asset must map to an ID in [the asset register](../planning/AssetRegister.csv).

Never copy sprites, sounds, logos, photographs or other proprietary content from Red Alert 2, Yuri's Revenge or fan-made assets without a compatible redistribution licence.
